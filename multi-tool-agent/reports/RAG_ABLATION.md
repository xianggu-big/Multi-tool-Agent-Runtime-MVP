# RAG 切块 / 维度消融（生成物）

> 由 `npm run rag:ablation` 从同一语料/查询自动生成；**请勿手改数字**。

## 0. 口径与边界

- 语料：本仓库 AGENTS.md、README.md、.env.example、docs/*.md、PROJECT_REPORT.md。
- Embedding：hash-ngram（离线词法替身）；本表只反映管线机制与成本，不代表真实语义模型效果。
- 相关 chunk：文本包含查询指定的唯一短语（自动标注）；不同切块下相关集合会重算。
- 指标：Recall@5 / MRR / nDCG@5；延迟为单查询平均墙钟（本地、内存索引）。
